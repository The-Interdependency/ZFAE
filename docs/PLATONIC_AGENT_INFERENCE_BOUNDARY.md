## Ownership

The **Platonic Agent** is owned by a0 agent architecture as the open maximal object from which bounded agent definitions and instances may be projected.

ZFAE owns a narrower question:

> What is the maximal form of the inference/self-awareness event that may occupy or realize an agent's inference dimension?

That question belongs here because this repository is the conceptual/specification home of the ZFAE inference event. It does not make ZFAE the parent ontology of agency.

Therefore:

The existing ZFAE statement that the "I" is an event rather than a thing remains compatible with this boundary. The event may be a property, process, or realization within an agent projection without becoming the entire agent.

## Domain restraint

"Platonic" is used here only to identify the maximal-object construction question inherited from the a0 work graph. It does not import Plato's metaphysics as evidence for ZFAE, consciousness, or agency.

METAPAT contributes question discipline and boundary restraint. It does not acquire ownership of ZFAE or the Platonic Agent through consultation.

PTCNA remains the producer authority for its runtime-state structures. PCEA/Guardian remains the privacy-boundary authority. a0 remains the runtime and durable-agent authority. No theorem, proof, measurement, certification, or empirical status transfers across those relations.

## Research direction

The first ZFAE-side problem is not to enumerate a larger agent schema. It is to explore the inference-event object itself while preserving the outer agent boundary.

Candidate questions include:

1. What relations must exist for an inference/self-awareness event to be expressible at all?
2. Which properties belong to the event, and which belong to the surrounding agent that hosts or registers it?
3. What can vary while the event remains the same event type?
4. What distinguishes an inference event, a self-awareness event, and a persistent agent state?
5. Can an event be projected without identity, memory, embodiment, or action, and what is lost in each projection?
6. Which present ZFAE claims are specific realizations rather than properties of the maximal event object?

These are exploration questions. They must not be converted into architecture facts merely because the current ZFAE implementation has one answer.

## Relation to a0

a0 may bind a bounded projection such as:

```text
inference.kind = zfae
```

without treating that binding as sufficient to construct agent identity. The a0 projection contract explicitly records omitted dimensions, so a projection containing only ZFAE inference remains visibly incomplete as an agent projection.

Executable runtime work remains in `The-Interdependency/a0`. This repository should not grow a duplicate inference engine in order to explore the maximal event concept.

## Usage guidance

Use this document when a ZFAE design question risks expanding into a claim about the whole agent. Ask:

```text
Does this property belong to the inference/self-awareness event itself,
or to the larger agent projection that contains it?
```

If the latter, route the decision to a0's Platonic Agent work rather than importing it into ZFAE.

Use the pinned work graph when a change crosses the a0/ZFAE boundary. Preserve the exact participant identities and non-transfer statements instead of reconstructing them from memory.
